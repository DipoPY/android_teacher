Расскажи про scope-функции let, run, with, apply, also. Как выбрать подходящую?

## Hints
1. Сравни их по двум осям.
2. this или it; результат лямбды или сам объект.
3. Scope-функции выполняют блок в контексте объекта и отличаются тем, как…

## Checklist
- Две оси: объект как this или it; возвращается объект или результат лямбды
- let — для nullable (?.let) и преобразований
- apply — настройка объекта (builder)
- also — побочные эффекты в цепочке
- run / with — блок с результатом; with — не extension
- Не злоупотреблять вложенностью: страдает читаемость

## Follow-ups
- Почему вложенные let с it ухудшают читаемость?

## Answer
Все scope-функции выполняют блок в контексте объекта. Различаются по двум осям:

| | объект как `this` | объект как `it` |
|---|---|---|
| возвращает результат лямбды | `run`, `with` | `let` |
| возвращает сам объект | `apply` | `also` |

Когда что:
- `?.let { }` — выполнить блок для non-null значения, преобразовать значение;
- `apply { }` — настроить объект: `Intent().apply { putExtra(…) }`;
- `also { }` — побочное действие в цепочке: логирование, валидация;
- `run { }` — вычислить результат в контексте объекта; `with(obj) { }` — то же, но obj передаётся аргументом (не extension, `?.` не работает).

Главное правило — читаемость: вложенные `let` с `it` быстро превращаются в загадку, лучше именовать параметры или разбивать код.
