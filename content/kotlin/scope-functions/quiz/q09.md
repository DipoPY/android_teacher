Что напечатает код?

```kotlin
var name: String? = "outer"
val len = name?.let {
    name = null
    it.length
}
println(len)
```

## Options
- [x] 5
- [ ] null
- [ ] NullPointerException
- [ ] Ошибка компиляции

## Explanation
В let передаётся значение на момент вызова — строка "outer". Присвоение `name = null` не меняет `it`.
