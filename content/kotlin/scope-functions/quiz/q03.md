Что напечатает код?

```kotlin
val list = mutableListOf(1, 2)
val r = list.also { it.add(3) }.map { it * 2 }
println(r)
```

## Options
- [ ] [2, 4]
- [x] [2, 4, 6]
- [ ] [1, 2, 3]
- [ ] true

## Explanation
also выполняет побочное действие (добавляет 3) и возвращает тот же список, к которому затем применяется map.
