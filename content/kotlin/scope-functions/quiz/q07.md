Что напечатает код?

```kotlin
val x = StringBuilder().run {
    append("a")
    append("b")
    length
}
println(x)
```

## Options
- [ ] ab
- [x] 2
- [ ] StringBuilder
- [ ] Unit

## Explanation
run возвращает результат последнего выражения лямбды — `length`, равный 2.
