Что выбрать, чтобы выполнить блок только для non-null значения и вернуть результат?

## Options
- [x] `?.let { }`
- [ ] `?.also { }`
- [ ] `with(x) { }`
- [ ] `?.apply { }`

## Explanation
`x?.let { … }` выполнит блок, только если x не null, и вернёт результат лямбды (или null).
