Какая функция идиоматична для побочного действия в цепочке (например, логирования) без изменения результата?

## Options
- [x] also
- [ ] let
- [ ] run
- [ ] with

## Explanation
also получает объект как `it` и возвращает его же: удобно для логов и проверок посреди цепочки.
