Если в теле data class явно переопределить toString(), компилятор не будет генерировать свою реализацию.

## Answer
true

## Explanation
Если equals(), hashCode() или toString() явно реализованы в теле data class (или объявлены final в родителе), компилятор использует их и не генерирует свои.
