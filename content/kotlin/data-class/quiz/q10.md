Какие модификаторы нельзя сочетать с data class?

## Options
- [x] abstract
- [x] open
- [x] sealed
- [x] inner
- [ ] internal

## Explanation
data class не может быть abstract, open, sealed или inner. Модификаторы видимости (internal, private) использовать можно.
