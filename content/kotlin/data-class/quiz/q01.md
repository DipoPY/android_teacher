Что напечатает этот код?

```kotlin
data class User(val name: String) {
    var age: Int = 0
}

val a = User("Ann").apply { age = 20 }
val b = User("Ann").apply { age = 30 }
println(a == b)
```

## Options
- [x] true
- [ ] false
- [ ] Ошибка компиляции
- [ ] Зависит от hashCode()

## Explanation
equals() и hashCode() генерируются только по свойствам из primary-конструктора. Свойство `age` объявлено в теле класса и в сравнении не участвует.
