Что напечатает код?

```kotlin
data class Key(var id: Int)

val key = Key(1)
val set = hashSetOf(key)
key.id = 2
println(set.contains(key))
```

## Options
- [ ] true
- [x] false
- [ ] Будет ConcurrentModificationException
- [ ] Ошибка компиляции

## Explanation
hashCode() зависит от `id`. После изменения ключ ищется в другой корзине и не находится. Поэтому ключи HashMap/HashSet должны быть неизменяемыми — используйте val.
