Зачем нужен `data object`?

## Options
- [x] Чтобы у синглтона был читаемый toString() и корректные equals/hashCode — например, в sealed-иерархиях
- [ ] Чтобы объект можно было копировать через copy()
- [ ] Чтобы создать несколько экземпляров объекта
- [ ] Чтобы объект сериализовался без аннотаций

## Explanation
data object (Kotlin 1.9) — это object с toString(), возвращающим имя объекта, и согласованными equals/hashCode. copy() и componentN() у него нет.
