Что напечатает код?

```kotlin
data class User(val name: String, val age: Int)

println(User("Ann", 30))
```

## Options
- [x] User(name=Ann, age=30)
- [ ] User@1b6d3586
- [ ] {name=Ann, age=30}
- [ ] User(Ann, 30)

## Explanation
Сгенерированный toString() выводит имя класса и пары `свойство=значение` для свойств primary-конструктора.
