Что напечатает код?

```kotlin
data class Point(val x: Int, val y: Int)

val (a, b) = Point(1, 2)
println(b)
```

## Options
- [ ] 1
- [x] 2
- [ ] Point(x=1, y=2)
- [ ] Ошибка компиляции

## Explanation
Деструктуризация позиционная: `b` получает component2(), то есть `y`. Имена переменных не обязаны совпадать с именами свойств.
