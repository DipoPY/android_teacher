Какое требование предъявляется к primary-конструктору data class?

## Options
- [x] Хотя бы один параметр, и все параметры объявлены как val или var
- [ ] Все параметры должны быть только val
- [ ] Конструктор может быть пустым
- [ ] Параметры могут быть без val/var

## Explanation
Primary-конструктор data class должен иметь хотя бы один параметр, и каждый параметр должен быть свойством (val или var).
