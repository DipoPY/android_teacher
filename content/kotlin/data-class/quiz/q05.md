Что напечатает код?

```kotlin
data class Box(val items: MutableList<Int>)

val a = Box(mutableListOf(1))
val b = a.copy()
b.items.add(2)
println(a.items)
```

## Options
- [ ] [1]
- [x] [1, 2]
- [ ] []
- [ ] Ошибка компиляции

## Explanation
copy() делает поверхностную копию: новый Box ссылается на тот же MutableList. Изменение через `b` видно и через `a`.
