Что компилятор генерирует для data class?

## Options
- [x] equals() и hashCode()
- [x] toString()
- [x] copy()
- [x] componentN() для деструктуризации
- [ ] clone()

## Explanation
Для свойств primary-конструктора генерируются equals/hashCode, toString, copy и component1..componentN. clone() не генерируется.
