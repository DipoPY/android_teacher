Что такое data class, что генерирует для него компилятор и какие у него ограничения?

## Hints
1. Вспомни, какие методы Any переопределяются и для каких свойств.
2. equals/hashCode, toString, copy, componentN; primary-конструктор; open/abstract/sealed/inner.
3. data class — это класс для хранения данных, для которого компилятор генерирует…

## Checklist
- equals/hashCode, toString, copy, componentN генерируются по свойствам primary-конструктора
- Свойства из тела класса не участвуют в equals/hashCode/toString
- Ограничения: минимум один параметр val/var, нельзя open/abstract/sealed/inner
- copy() — поверхностная копия
- var-свойства опасны в ключах HashMap/HashSet
- data object для синглтонов в sealed-иерархиях

## Follow-ups
- Почему опасно использовать data class с var-свойствами как ключ HashMap?
- Как исключить свойство из equals()?

## Answer
data class — класс для хранения данных. Для свойств **primary-конструктора** компилятор генерирует:

- `equals()` / `hashCode()` — сравнение по значению;
- `toString()` вида `User(name=Ann, age=30)`;
- `copy()` — копия с изменёнными полями (поверхностная);
- `component1()..componentN()` — для деструктуризации `val (name, age) = user`.

Свойства, объявленные в теле класса, в этих методах не участвуют — так можно исключить поле из сравнения.

Ограничения: минимум один параметр, все параметры — `val`/`var`; класс не может быть `open`, `abstract`, `sealed`, `inner`.

Подводные камни: `copy()` не копирует вложенные изменяемые объекты; `var`-свойства ломают поиск в `HashMap`/`HashSet` после изменения. Для синглтонов есть `data object` с читаемым `toString()`.
