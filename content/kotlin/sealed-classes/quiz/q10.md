Что верно про when по sealed-типу в Kotlin 1.7+?

## Options
- [x] when-выражение обязано быть исчерпывающим
- [x] when-оператор (без использования результата) тоже должен быть исчерпывающим
- [ ] Ветка else обязательна всегда
- [ ] Полнота проверяется в рантайме

## Explanation
Начиная с Kotlin 1.7 неполный when по sealed, enum и Boolean — ошибка и для выражений, и для операторов. Проверка идёт при компиляции; else не нужен, если все варианты перечислены.
