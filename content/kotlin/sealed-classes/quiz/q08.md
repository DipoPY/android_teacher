Что напечатает код?

```kotlin
sealed class Screen {
    data object Home : Screen()
    data class Details(val id: Int) : Screen()
}

println(Screen.Home)
```

## Options
- [x] Home
- [ ] Screen$Home@1a2b3c
- [ ] Screen.Home
- [ ] Home()

## Explanation
toString() у data object возвращает имя объекта. У обычного object был бы вывод вида `Screen$Home@1a2b3c`.
