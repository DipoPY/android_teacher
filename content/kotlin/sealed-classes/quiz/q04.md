Чем sealed interface отличается от sealed class?

## Options
- [x] Класс может реализовать несколько sealed-интерфейсов
- [x] У sealed interface нет конструктора и состояния
- [ ] Наследников sealed interface можно объявлять в других модулях
- [ ] По sealed interface нельзя делать исчерпывающий when

## Explanation
sealed interface снимает ограничение одиночного наследования: тип может входить в несколько иерархий. Правило «тот же модуль и пакет» и исчерпывающий when работают так же, как у sealed class.
