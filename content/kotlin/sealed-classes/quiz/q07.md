Когда sealed-иерархия лучше enum?

## Options
- [x] Когда у вариантов разные данные и одного варианта может быть много экземпляров
- [ ] Когда нужен список всех значений через values()
- [ ] Когда варианты — это просто набор констант
- [ ] Когда нужен порядковый номер ordinal

## Explanation
enum — фиксированный набор синглтонов с одинаковой структурой. Наследники sealed могут хранить разные данные: `Loading`, `Content(items)`, `Error(message)`.
