Главное преимущество sealed-иерархии?

## Options
- [x] Компилятор знает всех наследников, поэтому when без else может быть исчерпывающим
- [ ] Классы работают быстрее за счёт инлайна
- [ ] Наследники автоматически становятся data class
- [ ] Можно наследоваться из любого модуля

## Explanation
Набор наследников sealed-типа известен на этапе компиляции. Поэтому when проверяется на полноту: добавили нового наследника — компилятор покажет все места, где его нужно обработать.
