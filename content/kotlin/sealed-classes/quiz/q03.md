Что произойдёт при компиляции?

```kotlin
sealed interface Result
data class Success(val data: String) : Result
data class Failure(val error: Throwable) : Result

fun handle(r: Result): String = when (r) {
    is Success -> r.data
}
```

## Options
- [ ] Скомпилируется, для Failure вернётся пустая строка
- [x] Ошибка компиляции: when-выражение не исчерпывающее
- [ ] Скомпилируется, но упадёт в рантайме на Failure
- [ ] Скомпилируется с предупреждением

## Explanation
when как выражение по sealed-типу обязан покрывать всех наследников (или иметь else). Не хватает ветки `is Failure`.
