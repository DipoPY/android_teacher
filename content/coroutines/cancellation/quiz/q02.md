Что произойдёт после `job.cancel()`?

```kotlin
val job = launch(Dispatchers.Default) {
    repeat(5) { i ->
        Thread.sleep(100) // блокирующая работа без точек приостановки
        println("шаг $i")
    }
}
delay(150)
job.cancel()
```

## Options
- [ ] Корутина остановится сразу после cancel()
- [x] Будут напечатаны все 5 шагов
- [ ] cancel() бросит исключение
- [ ] Ошибка компиляции

## Explanation
В цикле нет точек проверки отмены: Thread.sleep() блокирует поток и отмену не проверяет. Нужны ensureActive(), yield() или приостанавливающий delay().
