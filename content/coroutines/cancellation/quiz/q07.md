Что напечатает код?

```kotlin
val job = launch {
    try {
        delay(1000)
    } finally {
        println("finally")
    }
}
delay(100)
job.cancelAndJoin()
println("done")
```

## Options
- [ ] done
- [x] finally, затем done
- [ ] done, затем finally
- [ ] Ничего

## Explanation
Отмена прерывает delay исключением CancellationException, выполняется finally. cancelAndJoin() дожидается завершения корутины, поэтому done печатается после.
