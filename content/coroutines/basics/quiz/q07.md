Сколько примерно займёт выполнение?

```kotlin
suspend fun main() = coroutineScope {
    val a = async { delay(100); 1 }
    val b = async { delay(100); 2 }
    println(a.await() + b.await())
}
```

## Options
- [x] ~100 мс
- [ ] ~200 мс
- [ ] ~0 мс
- [ ] Всегда 200 мс, независимо от диспетчера

## Explanation
Оба async стартуют сразу и ждут параллельно, поэтому общий результат готов примерно через 100 мс.
