Что делает `withContext(Dispatchers.IO) { … }`?

## Options
- [x] Выполняет блок на другом диспетчере, приостанавливая вызывающую корутину, и возвращает результат
- [ ] Запускает новую корутину и сразу возвращает Job
- [ ] Блокирует текущий поток до завершения блока
- [ ] Меняет диспетчер для всех корутин в scope

## Explanation
withContext переключает контекст только для блока, дожидается его и возвращает результат. Это стандартный способ сделать main-safe suspend-функцию.
