Что напечатает код?

```kotlin
fun main() = runBlocking {
    launch { println("A") }
    println("B")
}
```

## Options
- [ ] A, затем B
- [x] B, затем A
- [ ] Только B
- [ ] Порядок случайный

## Explanation
launch только планирует корутину. Родительская продолжает выполнение и печатает B; дочерняя запускается, когда поток освобождается. runBlocking дождётся ребёнка, поэтому A тоже напечатается.
