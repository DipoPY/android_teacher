Какой Dispatcher использовать для сетевых запросов и работы с диском?

## Options
- [x] Dispatchers.IO
- [ ] Dispatchers.Default
- [ ] Dispatchers.Main
- [ ] Dispatchers.Unconfined

## Explanation
IO рассчитан на блокирующий ввод-вывод и допускает много потоков. Default — для CPU-вычислений, Main — для UI.
